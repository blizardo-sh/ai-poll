# Занятие 1: голосование

https://blizardo-sh.github.io/ai-poll/lesson1/

Одна страница для голосования и управления. Вход и Google-аккаунт не нужны. Кнопки доступны сразу. Результаты обновляются во время голосования, разбор открывается отдельно.

Панель управления занимает один компактный ряд. QR-код для голосования расположен справа от вопроса на большом экране и ниже ответов на телефоне. Ссылка «QR-код» вверху страницы ведёт к нему.

Клавиши: S — начать, C — закончить, O — показать разбор и завершить приём ответов, N — следующий вопрос. Работают и в русской раскладке; при вводе запроса отключены. Действия доступны каждому, у кого открыта страница.

Firebase автоматически присваивает браузеру анонимный идентификатор. Каждый браузер записывает только свой голос. Для подсчёта страница читает варианты текущего раунда по этим идентификаторам. Имена и email не собираются. Итоги обновляются и без открытой страницы ведущего.

Для сборки: `npm ci && npm run build`. Для тестов правил нужны Firebase CLI и Java 21: `firebase emulators:exec --project demo-lesson-one --only database,auth "npm run test:rules"`. Браузерный тест находится в tests/browser.mjs и использует только локальные эмуляторы.

Правила database.rules.json содержат только ветку lesson1. Перед публикацией объедините её с текущими правилами базы. Список допустимых вариантов и пояснения заполняются отдельно.

Изображение котов предоставлено автором занятия. Синтетический архив lab1.zip предназначен для совместной работы на встрече.
