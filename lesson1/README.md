# Занятие 1: голосование

https://blizardo-sh.github.io/ai-poll/lesson1/

Участники и преподаватель открывают одну страницу. После Google-входа преподавателю доступны кнопки управления. Голоса видны сразу. Разбор появляется по команде преподавателя.

Для сборки: `npm ci && npm run build`. Для тестов правил нужны Firebase CLI и Java 21: `firebase emulators:exec --project demo-lesson-one --only database,auth "npm run test:rules"`. Браузерный тест находится в tests/browser.mjs и использует только локальные эмуляторы.

Не публикуйте database.rules.json поверх всех правил существующего проекта: файл содержит только ветку lesson1. Объедините её с текущими правилами. Закрытая настройка lesson1/teacherEmail задаёт разрешённый Google-аккаунт; lesson1/teacherAccess равна true. Пояснения и список допустимых вариантов заполняет организатор отдельно.

Изображение котов предоставлено автором занятия. Синтетический архив lab1.zip предназначен для совместной работы на встрече.
